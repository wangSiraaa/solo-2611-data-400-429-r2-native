# Locality-constrained gang placement starter

Run `/opt/homebrew/bin/python3.11 probe.py`. Nodes are local directories plus separate logical cpu/io ledgers. The current Allocator.place_one performs first-fit for one member and Dispatcher.reserve_one immediately launches a real worker from the selected replica. A one-member stage works. The flexible/constrained case has a complete legal placement but first-fit occupies its only scarce node and leaves a real READY process waiting for GO. The independent finite assignment enumerator is an oracle for this small placement fixture, not the target gang allocator or DAG scheduler.

The workflow contract is described in the question: nodes declare capacities; each stage has dependencies and members, each member has resources, allowed_nodes, factor, and either an input replica map (node to path/sha256) or an explicit parent-worker reference plus replicate_to. All root replica files are immutable and the domain is fixed. Derived replicas require actual copy of completed parent output and recorded bytes, not a log-only surrogate. A worker input is one JSON array of unique row_id and integer value, at most 200 rows; factor is an integer -10..10. Missing/corrupt replicas are rejected, not treated as permission to read another node's file. Mature matching/constraint libraries may be used; real processes and files must still execute.
